## 👤 2. 타겟 유저 페르소나

### 🎮 메인 사용자 — 감성 소비형 게이머

* **인구통계학적 특성:**  
  게임과 음악을 함께 즐기는 10~20대 사용자.  
  주로 학생이나 젊은 게이머들이 사용하며, 유튜브 플레이리스트·스팀·디스코드 같은 플랫폼을 자주 이용함.

* **불편함:**  
  게임 종류가 너무 많아 자신에게 맞는 게임을 찾기 어려워함.  
  또한 게임 분위기에 어울리는 음악을 따로 검색해야 하는 점을 번거롭게 느낌.

* **기대하는 것:**  
  현재 기분이나 분위기에 맞는 게임과 음악을 한 번에 추천받고 싶어함.  
  “힐링”, “신나는”, “새벽 감성”, “집중” 같은 키워드 기반 추천을 기대함.

---

### 🎧 서브 사용자 — 스트레스 해소형 사용자

* **인구통계학적 특성:**  
  공부나 일상 스트레스를 해소하고 싶은 20대 대학생 및 일반 사용자.  
  인디게임, Lo-fi 음악, 감성 콘텐츠를 자주 소비함.

* **불편함:**  
  쉬고 싶을 때 어떤 게임과 음악을 선택해야 할지 고민하는 경우가 많음.  
  여러 플랫폼을 오가며 콘텐츠를 찾는 과정이 귀찮다고 느낌.

* **기대하는 것:**  
  편안한 분위기의 UI와 함께 자신의 취향에 맞는 게임·음악 조합을 추천받고 싶어함.  
  쉽고 빠르게 새로운 취향을 발견하는 경험을 기대함.

## 🗺️ 4. 화면 설계 및 유저 플로우
* 사용자가 우리 웹사이트에 접속하여 목표를 달성하기까지의 클릭 흐름을 단계별로 작성합니다.
 
 1. 서비스 진입 및 게임 정보 선택

유저가 웹사이트 메인 페이지에 접속

현재 플레이 중인 [게임 장르](예: RPG, FPS, 전략)를 선택하거나, 원하는 [게임 분위기](예: 웅장한, 긴박한, 평화로운) 버튼을 클릭.

사용자의 선택은 랜덤 추천의 '카테고리' 기준이 됨.

2. 랜덤 음악 추천 및 결과 확인

선택을 완료하면 애니메이션 효과와 함께 해당 카테고리 내의 노래 중 하나가 랜덤으로 매칭되어 화면에 나타남.

추천된 곡의 제목, 아티스트 정보, 그리고 앨범 커버 이미지가 화면 중앙에 강조됨.

'다시 추천받기' 버튼을 배치하여, 마음에 들지 않으면 언제든 다른 랜덤 곡을 뽑을 수 있도록 함.

3. 감상 및 즐겨찾기

추천된 곡의 [재생 버튼]을 눌러 게임과 동시에 음악 감상.

유저가 선택된 노래가 마음에 든다면 [즐겨찾기(별)] 아이콘을 클릭

화면 하단 알림창을 통해 저장 완료 메시지를 확인

4. 나만의 게임 플레이리스트 관리

상단 메뉴의 [My Playlist] 탭으로 이동

지금까지 랜덤 추천을 통해 '즐겨찾기' 했던 곡들이 리스트 형태로 정렬되어 있음.

저장된 리스트를 보며 나중에 같은 게임을 할 때 다시 들을 수 있도록 함.
