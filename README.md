## ⭐ 3. 핵심 기능
> 프론트엔드 환경에서 3주 내에 구현할 수 있는 핵심적인 기능 딱 3가지를 정의합니다.
1. **[기능명:상황에 어울리는 랜덤노래]**: (게임 모드별 맞춤 플레이리스트 추천
유저가 직접 게임의 상황(예: 전투 중, 탐험 중, 로비 대기 등)을 선택하면, 해당 상황에 최적화된 분위기의 음악 리스트를 보여주는 기능으로, 예를 들어 유저가 '전투 모드' 버튼을 누르면, 게임 상황에 어울리는 강렬한 음악 리스트를 유저에게 제공하여  유저가 이를 확인하고 재생할 수 있습니다.  )
2. **[기능명:유저의 취향고려]**: (음악 장르 및 분위기 필터링
유저가 선호하는 음악 스타일을 게임에 입힐 수 있는 필터 기능으로, 예를 들어 유저가 "FPS 게임을 할 때 나는 'Lo-fi' 느낌의 음악을 듣고 싶어"라는 니즈를 표하면 [게임 장르] x [음악 스타일] 조합을 통해 유저가 자신의 취향에 맞는 게임용 BGM을 빠르고 직관적으로 찾을 수 있도록 돕습니다.)
3. **[기능명:음악 저장]**: (나만의 게임 플레이리스트 저장
추천받은 곡들 중 유저가 가장 마음에 들었던 곡들을 따로 모아 '내 게임 플레이리스트'로 저장하는 기능으로, 유저가 선택한 곡들을 리스트 형태로 앱 내에 저장하거나 즐겨찾기할 수 있습니다. )
